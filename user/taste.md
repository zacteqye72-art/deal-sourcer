# 我的音乐品味

> 这是 Claudio 唯一会读取的"我是谁"。写得越具体，DJ 越懂你。

## 我喜欢的（按强度从高到低）
- **City Pop**：山下达郎、竹内まりや、角松敏生 — 周末早晨/做饭时
- **后摇**：Mono、World's End Girlfriend、惘闻 — 写代码、深夜
- **独立流行**：陈绮贞、张悬、雷光夏 — 通勤、安静的下午
- **Lo-fi Hip Hop**：Nujabes、J Dilla — 长会议背景
- **古典**：肖邦夜曲、Erik Satie — 入睡前 30 分钟

## 我不要的
- 任何"DJ 嗨曲"、EDM、Future Bass
- 中文 rap（除非我特别说今天想听）
- 过分情歌套路、口水流行
- 节奏比 BPM 100 还激进且无 build-up 的曲子（清晨场景）

## 季节/天气偏移
- 雨天：偏向后摇、坂本龙一、ECM 系
- 晴天且温度 > 20°C：city pop、bossa
- 寒冷阴天：低保真、慢核

## 听歌的"红线"
- 早 7:00 之前 / 晚 23:00 之后：BPM ≤ 90
- 工作时段（写代码）：歌词 ≤ 30%，避免人声主导
- 健身：80–100s 的港乐 + 90s 日摇可以试

## 我特别讨厌的曲子（绝对不要播）
- 任何带有"喊口号"段落的歌
- 大段 auto-tune

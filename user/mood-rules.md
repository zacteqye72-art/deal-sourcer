# 情绪规则

> Claudio 每小时做一次"情绪检查"，根据这些规则在不打扰的前提下调整声音。

## 输入信号
- **用户反馈**：PWA 上的👍/👎、跳过率、`/api/feedback`。
- **日历**：会前/会后 30 分钟。
- **天气**：温度、降水、气压。
- **时间**：清晨 / 上午 / 下午 / 傍晚 / 深夜。
- **听歌历史**：最近 60 分钟的曲风熵。

## 规则（按优先级）
1. **跳过率 > 40%（最近 5 首）** → 立刻换风格池，并在下一首前用 12s 播报承认："看起来这一段不对你的胃口，我换一种试试。"
2. **会议前 5 分钟**（calendar） → 强制 fade out，30 分钟后再恢复。
3. **气压骤降 + 阴天** → 偏移到"雨天后摇"，避开高频明亮的 city pop。
4. **连续 3 首同 BPM 区间** → 下一首换 ±15 BPM，避免疲劳。
5. **深夜 23:00 后** → 自动收紧到 BPM ≤ 90 的池子，不论用户在听什么。
6. **冷启动**（无任何反馈）→ 选 anchors 中的"上次没播过"的歌单的随机 3 首。

## 播报"温度"
- 默认：**安静、像深夜电台 DJ**。
- 跳过率高时：**克制地承认偏差**，不解释太多。
- 早间：**清醒但不亢奋**，一句天气 + 一句歌单缘由。
- 晚间：**几乎只用气声**，一首歌之间最多 8 秒。
